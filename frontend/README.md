# Weather App — Frontend

Cliente React (Vite) para la Weather App. Diseño glassmorphism. Ver el README principal del repositorio para la documentación completa del proyecto.

## Desarrollo

```bash
npm install
cp .env.example .env
npm run dev
```

Requiere que el backend (`../backend`) esté corriendo en `http://localhost:8080` (o la URL configurada en `VITE_API_BASE_URL`).
